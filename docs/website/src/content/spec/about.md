## 这是什么

**星露谷启动器**是一款面向《星露谷物语》的 Windows 桌面工具，把**游戏实例、SMAPI、Mod、存档与联机**收进一个窗口里。

- 项目地址：[GitHub](https://github.com/OrangeArtc0915/SVE_mananger) / [Gitee 文件库](https://gitee.com/orangearc655743/SVE_mananger_File)
- 下载地址：[GitHub Releases](https://github.com/OrangeArtc0915/SVE_mananger/releases) / [Gitee 发行版](https://gitee.com/orangearc655743/SVE_mananger_File/releases)
- 反馈与交流：QQ 群 **1034243331**
- 作者：**mmm**

## 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809 及以上 / Windows 11 |
| 架构 | x64 |
| 运行时 | 不需要单独安装 .NET，exe 已自包含 .NET 8 |
| 权限 | 普通用户即可，不需要管理员权限 |
