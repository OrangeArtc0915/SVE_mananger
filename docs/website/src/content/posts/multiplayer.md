《星露谷物语》原版联机走 UDP，主机需要把自己的端口暴露到公网。启动器用**樱花 FRP** 帮你完成这一步。

## 开房

1. 到「联机功能」页，把樱花 FRP 面板里的**访问密钥**填进来，点「验证并加载」
   - 免费账号也能开隧道；密钥等价于账号密码，只存在本机 `Data\Settings.json`
2. 点「准备 frpc」，从樱花 FRP 官方接口下载官方客户端（只下一次，带 MD5 校验）
3. 填隧道名 → 「加载节点」挑一个可用节点 → 「创建 UDP 隧道（本地端口 24642）」
4. 在「我的 UDP 隧道」里点「启动」，等页面出现连接地址

## 把地址发给朋友

启动成功后页面会同时给出两种写法：

- **域名地址**，形如 `frp-xxx.com:10086`
- **IP 地址**，形如 `114.51.4.191:10086`

两者任选其一，各有一个「复制」按钮。朋友在游戏里走 **合作 → 加入局域网游戏 → 输入地址**。

> 房主的存档需要有**联机小屋**，否则朋友进来会卡在角色选择界面。

## 面板就在启动器里

页面右侧内嵌了樱花 FRP 的**官方网页版面板**：建隧道、改名、改端口、删除，登录一次之后都在里面做，不用切到浏览器。

## 两个注意点

- 只有 **UDP** 隧道能用于星露谷，TCP 隧道用不了
- **原版没有密码保护**，不联机时记得点「停止隧道」
