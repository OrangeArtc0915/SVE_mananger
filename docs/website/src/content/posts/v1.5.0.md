## 这一版做了什么

这一版主要补上"启动器之外还得手动做的事"：存档要自己备份、Mod 组合要来回勾、压缩包要一层层点进来。

### 新增「工具箱」，第一个工具是存档管理

侧栏多了一个**工具箱**，点进去是「存档管理」：

- 列出游戏自己的存档目录（`%APPDATA%\StardewValley\Saves`）里的每一份存档：玩家名、农场名、进度、金钱、游玩时长、五项技能、最后保存时间与体积
- 每份存档可以**一键备份**，也可以「全部备份一次」
- 「备份与回滚…」里能选任意一份备份**回滚**，而且**回滚前会先自动给当前存档打一份快照**，所以回滚本身也能反悔
- 备份存在启动器自己的 `Data\save-backups\` 里，**不往游戏存档目录塞文件**，免得被 Steam 云同步带走
- 游戏运行中只允许备份（会提示这时候备份的是上次保存的状态），**回滚会先要求你退出游戏**

> 启动器只读存档、只写自己的备份目录，**不会删改你的任何存档文件**。

### Mod 配置档：一套组合一键切

调好想要的 Mod 启停组合（比如"美化包 / 剧情包 / 只留性能优化"），点「配置档 → 保存当前状态」存下来，之后一键切换。支持覆盖、重命名、导出成 json、从 json 导入。

配置档只记录**启停状态**、只改文件夹名开头的点，不动任何 Mod 文件；对应关系用的是 Mod 的 UniqueId，所以禁用改名之后不会错乱。

### 拖拽安装

把 `zip` / `rar` / `7z` / `tar` / `gz` 直接**拖到启动器窗口任意位置**，就会自动切到 Mod 管理页开始导入；拖一个 Mod 文件夹进去也可以。「导入 Mod」按钮现在也支持一次选多个包。

### 侧栏「使用手册」

启动器里就能翻官网的使用手册（Wiki），不用再开浏览器；右上角留了「用浏览器打开」的退路。

### 首页小组件可自定义

主页的月历 / 现实天气 / 每日一言：

- 按住卡片就能**拖动调整顺序**
- 右上角「自定义」菜单可以勾选显示 / 隐藏，或者恢复默认顺序
- 顺序与显隐会记住，下次打开还是你排的样子

### 其它

- 官网 Wiki 补了「存档管理」与「Mod 配置档」两篇，并修正了此前与实现不符的说明（实例并不隔离 Mod 与存档目录）
- 启动器自身的进程检测与目录删除逻辑做了收敛，`SideBar` 里一处会导致控制台报错的脚本问题一并修掉
