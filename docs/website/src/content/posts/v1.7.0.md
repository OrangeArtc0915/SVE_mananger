## 这一版做了什么

上一版开了「工具箱」，但只有存档管理一个工具。这一版把它填满：**出问题时需要挨个问一圈的信息，现在都能在一个页面里看到**；另外把几个一直只能改配置文件、界面上没有入口的设置补上了控件。

### 工具箱现在有五个工具

侧栏「工具箱」的列表页一张卡一个工具，点「打开」在页内切进去：

| 工具 | 干什么 |
| --- | --- |
| 存档管理 | 存档摘要、备份与回滚（上一版已有） |
| **环境体检** | 一次扫完环境，逐条给结论 |
| **Mod 冲突检查** | 找出「装了却没生效」的那些 Mod |
| **SMAPI 日志分析** | 指出是哪个 Mod 在报错 |
| **原版文件还原** | 把被覆盖的游戏原版文件救回来 |

#### 环境体检

启动器（版本、运行时、**数据目录能不能写**）、游戏目录、SMAPI、Mods 统计、依赖与版本要求、Mod 冲突、磁盘空间、日志与数据目录占用、上次自动更新残留 —— 一份页面全扫完，每条给「正常 / 提示 / 注意 / 问题」四级结论。

有两项是以前完全看不到、却经常是问题根源的：

- **数据目录能不能写**。程序放在 `Program Files` 这类受保护的位置时写不进去，但失败往往要等到你改设置才浮出来，报错也看不出所以然。体检会直接告诉你。
- **Mod 要求的 SMAPI / 游戏版本**。`manifest.json` 里可以声明「至少要什么版本」，装低了 SMAPI 会拒绝加载，而报错只在游戏控制台里滚过去 —— 现在会提前比对并列出是哪几个 Mod。

工具条上「复制报告」把整份结论复制成纯文本，可以直接贴到群里提问；「导出反馈包」生成一个 zip，里面是**体检报告 + Mod 清单 + 设置摘要 + 最近 5 份运行日志**。

> **密钥不会进包**：设置摘要只记录「有没有配置」，另外所有文本在落包前还会把密钥的实际值抹掉。包是你自己选位置保存、自己决定发不发。

#### Mod 冲突检查

一次列出三类「确实有毛病」的装载方式：

- **重复 ID**：多个**已启用**的 Mod 共用同一个 `UniqueID`，SMAPI 只会加载其中一个，另一个等于白装（留一份禁用着的旧版本不算冲突，不会报）
- **加载失败**：`manifest.json` 读不出来
- **不会被加载**：Mods 下的目录里没有 `manifest.json`（压缩包多套了一层、或者装的是要手动覆盖的 XNB 包），以及直接丢在 Mods 根目录下的文件

> 这个工具**只看磁盘上已有的信息**，不解析内容包里的 `content.json`，所以「两个美化包抢同一张贴图」这类查不出来 —— 那种要看日志分析或游戏里的实际表现。

#### SMAPI 日志分析

读最近一份 SMAPI 日志，按**来源**（SMAPI 本体、游戏本体、每个 Mod）统计错误与警告，把「谁在刷屏」排在前面；另外列出被 SMAPI 明确跳过的 Mod 与去重后的关键错误原文。日志文件按官方说法在 `%APPDATA%\StardewValley\ErrorLogs\`，取最近改动的那一份。

两个细节：

- 同一条消息重复刷屏时，样例只留一份，不然三行样例会被同一句话占满
- **异常堆栈的续行算作上一条错误的一部分**，不会被当成一条条独立错误 —— 否则一个崩溃堆栈就能把某个 Mod 的错误数从几条刷到几十条，排名也就没意义了

#### 原版文件还原

有些 Mod（XNB 替换、Content 覆盖）会直接覆盖游戏原版文件。启动器在覆盖前一直会留一份 `.bak-<时间戳>` 在原文件旁边，这一版把它用起来了：

- **已登记**的条目记着「是哪个安装包覆盖的」，**能确定是原版**；索引建立之前留下的 `.bak-` 会标成**未登记**（可能是原版，也可能是上一个 Mod 覆盖后的版本），工具不替你下结论
- 还原时先把当前文件另存为 `<文件名>.before-restore-<时间戳>`，再把备份复制回去，**备份本身也保留** —— 所以还原这一步同样能反悔
- Mods 目录里的 `.bak-` 是旧版 Mod，不会被列进来

### 几个设置终于有界面了

以前这几项只存在于 `Settings.json` 里，得手工编辑，现在都在「设置」页：

| 位置 | 设置 | 说明 |
| --- | --- | --- |
| Mod 与下载 | **覆盖前备份** | 默认开。覆盖游戏原版文件前是否先留一份 `.bak-`；关掉后原版文件还原就没有东西可还原了 |
| 存储与日志 | **日志上限** | 保留 8 / 16 / 32 份，单份超过 4 / 8 / 16 MB 就换新文件（下次启动生效） |
| 存储与日志 | **存档备份** | 每个存档保留 5 / 10 / 20 / 30 份；回滚前是否自动打快照 |
