## 第一步：新建实例并选择游戏目录

在「游戏实例」里新建一个实例，指向你的《星露谷物语》安装目录。

- 想要纯净体验：选**原版**，直接拉起 `Stardew Valley.exe`
- 想玩 Mod：选 **Mod 端**，走 SMAPI 启动，Mod 管理功能只对这个实例生效

一套原版 + 多套 Mod 端可以同时存在，各自的 Mod 目录、存档目录与 SMAPI 配置互不干扰。

## 第二步：先装 SMAPI，再装 Mod

在「资源中心」点「下载 SMAPI」，官方与启动器云端镜像两条线路任选：

| 线路 | 来源 | 说明 |
| --- | --- | --- |
| 官方 | GitHub Releases（Pathoschild/SMAPI） | 总是取最新版 |
| 云端镜像 | 本项目 resource 分支 | 国内可达性更好，可选 Gitee 源 |

装的过程中会**弹出一个黑色控制台窗口**，那是 SMAPI 官方安装器自己的窗口，不要关掉它，几秒后会自动关闭。

装完启动器会校验游戏目录里的 `StardewModdingAPI.exe` 与 `smapi-internal`，并显示当前版本。之后把 Mod 压缩包导入 Mod 库（支持 `zip` / `rar` / `7z` / `tar` / `gz`），或直接在「在线浏览」里下载安装；缺前置会顺手提醒。

## 第三步：点启动

回到启动页按下按钮即可。启动前会校验 Mod 与前置依赖，游戏日志实时显示在下方面板里。

想和朋友一起种地，就到「联机功能」开一条 UDP 隧道 —— 详见[用樱花 FRP 和朋友联机](/posts/multiplayer/)。
