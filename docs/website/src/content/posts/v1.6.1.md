## 这一版做了什么

这一版主要补上"启动器之外还得手动做的事"：存档要自己备份、Mod 组合要来回勾、压缩包要一层层点进来。

### 先修掉四处不一致

- **弹窗不再是系统样式**：原来的提示框是系统 `MessageBox`（灰底、方角、系统字体、系统按钮），和启动器完全是两个风格。现在全部换成自绘弹窗：卡片圆角、主题配色、启动器自己的按钮控件，分信息 / 询问 / 警告 / 错误四种语气，没有系统标题栏所以按住卡片就能拖。
- **所有窗口都不再带系统标题栏**：二级窗口（关于、扩展管理、新建实例、输入框…）统一改用与主窗口同一套 `WindowChrome` 方案，自绘「浮起来的圆角卡片 + 投影」外框，右上角有最小化 / 关闭，双击标题区域最大化。
- **更新完一定会自动重开启动器**：替换成功会重开新版本；万一替换失败，回滚旧版本后同样会重新打开，不会把人晾在"启动器没了"的状态。
- **Gitee 也能一键更新了**：Gitee 的单个附件上限是 100 MB，装不下这个 150 MB 的单文件 exe，那边只传得上发布包 zip。启动器现在会自己把 zip 解出 exe 再替换，设置里也多了「启动器更新线路」开关（GitHub / Gitee）。

### 新增「工具箱」，第一个工具是存档管理

侧栏多了一个**工具箱**，点进去是「存档管理」：

- 列出游戏自己的存档目录（`%APPDATA%\StardewValley\Saves`）里的每一份存档：玩家名、农场名、进度、金钱、游玩时长、五项技能、最后保存时间与体积
- 每份存档可以**一键备份**，也可以「全部备份一次」
- 「备份与回滚…」里能选任意一份备份**回滚**，而且**回滚前会先自动给当前存档打一份快照**，所以回滚本身也能反悔
- 备份存在启动器自己的 `Data\save-backups\` 里，**不往游戏存档目录塞文件**，免得被 Steam 云同步带走
- 游戏运行中只允许备份（会提示这时候备份的是上次保存的状态），**回滚会先要求你退出游戏**

> 启动器只读存档、只写自己的备份目录，**不会删改你的任何存档文件**。

### Mod 配置档：一套组合一键切

调好想要的 Mod 启停组合（比如"美化包 / 剧情包 / 只留性能优化"），点「配置档 → 保存当前状态」存下来，之后一键切换。支持覆盖、重命名、导出成 json、从 json 导入。

配置档只记录**启停状态**、只改文件夹名开头的点，不动任何 Mod 文件；对应关系用的是 Mod 的 UniqueId，所以禁用改名之后不会错乱。

### 拖拽安装

把 `zip` / `rar` / `7z` / `tar` / `gz` 直接**拖到启动器窗口任意位置**，就会自动切到 Mod 管理页开始导入；拖一个 Mod 文件夹进去也可以。「导入 Mod」按钮现在也支持一次选多个包。

### 侧栏「使用手册」

启动器里就能翻官网的使用手册（Wiki），不用再开浏览器；右上角留了「用浏览器打开」的退路。

### 首页小组件可自定义

主页的月历 / 现实天气 / 每日一言：

- 按住卡片就能**拖动调整顺序**
- 右上角「自定义」菜单可以勾选显示 / 隐藏，或者恢复默认顺序
- 顺序与显隐会记住，下次打开还是你排的样子

### 还能自己调

除了工具箱和配置档，这一版还塞进一批“自己调”的东西。

**三个新小组件**：主页从 3 张卡片变成 6 张。

- **存档概览**：读游戏存档目录里最近保存的那份，显示玩家名 / 农场名、进度、金钱、游玩时长和五项技能；读不到就写「还没扫到存档」
- **自定义图片**：自己选一张 `jpg` / `png` / `bmp` / `gif`，启动器会复制一份到 `Data\Homepage\`，之后原图动了删了都不影响；卡片上有「换图」「移除」
- **Mod 概览**：当前实例名、「共 N 个 · 启用 X · 禁用 Y」和 SMAPI 版本；原版实例、没装 SMAPI 各有对应提示

「自定义」菜单里还多了「导出布局…」与「导入布局…」：导出一个 json（顺序 + 显隐 + 图片挂件的图路径），换机或重装后导回来就行。

> 导入时如果那台机器上缺图，会提示「需要重新选一张」。拖动排序与显示 / 隐藏照旧，都自动记住。

**自定义外观**，在「设置 → 外观」：

- **自定义强调色**：一条色相滑块（0-359），拖动即改即看；也可以在输入框填 `#E67E22` 这样的色值点「按色值」，点「用预设配色」则回到四套预设
- **面板不透明度**：更透（60）/ 默认（78）/ 更实（90）/ 不透明（100），影响侧栏、标题栏与卡片这类半透明面板

**侧栏导航也能排**：8 个导航项用「上移」「下移」调顺序，「收起」/「显示」决定藏不藏，底部有「恢复默认顺序」；顺序与显隐存进设置，重启后保持。

### 启动器能自己更新了

「设置 → 游戏与实例 → 更新检查」里多了**检查启动器更新**按钮：

- 查到新版本，按钮直接变成「下载并更新到 vX.Y.Z」—— 下载、校验、替换、重启一气呵成，进度就显示在按钮下面
- 更新只替换启动器那一个 exe，`Data\`（设置、实例、存档备份、扩展、背景）原样不动
- 万一替换失败，会自动把旧版本换回来，不会留下一个打不开的目录
- 更新线路可以在 GitHub / Gitee 之间自己选，选的那条取不到版本信息时自动换另一条
- 发布页只放了整包 zip 时（Gitee 的单个附件上限 100 MB，装不下 150 MB 的单文件 exe），启动器会自己把 zip 解出 exe 再替换
- 不想手动点，就打开「启动时自动检查更新」，每次启动在后台查一次，有新版会问你要不要现在更（默认关）

### 主页可以自己写扩展了

主页的小组件现在是开放的：写一个 C# 类实现 `IHomepageWidgetPlugin`，编译成 dll 丢进扩展目录，在主页「自定义 → 扩展管理…」里手动启用，它就会作为一张卡片出现在小组件区，一样能拖动排序、一样能收起。

- 扩展**只能产出文字与数字**：正文 / 标签取值 / 进度条 / 分隔线，卡片上没有任何可点击的行
- 扩展**拿不到任何写入口**：不能写文件、不能写日志、不能启动游戏或改设置，只能做只读 GET 联网取数和读启动器已有的数据
- 启用前会做一次**加载前的安全检查**（只读元数据、不运行代码）：命中「读写文件 / 注册表 / 非托管调用 / 动态生成代码 / 启动其它进程」就拒绝加载，并在扩展管理里写明是哪个 dll 用了哪个类型
- 契约程序集与示例工程都在仓库里（`src/StardewLauncher.Api` 与 `samples/StardewLauncher.SampleWidget`），官网 Wiki 有完整教程

### 界面动起来了

这一版把动效整套重做：开场面板放大淡入、侧栏逐项滑入，切页左右交接且内容分块错峰进入，按钮按下有水波扩散，背景带缓慢的呼吸光；窗口最小化时会自动停掉视频、动图与环境动效，不白烧 CPU。主页的自定义菜单也换成了与整体一致的自绘样式。

### 许可证改为保留所有权利

从这一版起，本启动器**保留所有权利**，但明确允许**原样转发**（不改动地分享安装包）。二次修改、重新打包发布不在授权范围内。详见仓库里的 `LICENSE`。

- 官网 Wiki 补了「存档管理」与「Mod 配置档」两篇，并修正了此前与实现不符的说明（实例并不隔离 Mod 与存档目录）
