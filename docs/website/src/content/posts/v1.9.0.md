## 这一版做了什么

上一版（v1.8.0）补的是「装好 Mod 之后」的三件事。这一版换了个方向：**把散落各处的信息收拢起来**——第一次打开该干什么、Mod 之间的依赖长什么样、一套 Mod 怎么整套换、下载和安装到底跑到哪一步了。

一次上新七个功能，工具箱从五个工具扩到八个。

### 首次运行配置向导

第一次打开启动器时（没跑过向导、一个实例都没有、设置里也没记过游戏目录），会先弹一个四步向导：

**欢迎 → 选游戏目录 → 检查 SMAPI → 建第一个实例**

第 2 步会先自动探测（Steam / GOG / Xbox / 常见路径），也可以手动选目录；选中后**立刻校验**，通过了才能进下一步 —— 不会让你带着一个错的目录一路走到最后。

> 只在三个条件都满足时才弹一次。装好之后正常启动不会再打扰你；想重看可以到「设置 → 游戏与实例」里重新跑。

### 工具箱多了三个

侧栏「工具箱」原本五个工具，这一版加了三个，都在同一个列表页里：

| 新工具 | 干什么 |
| --- | --- |
| **Mod 依赖关系图** | 把 `manifest.json` 写的前置关系画成分层图 |
| **批量 Mod 信息分析** | 一次跑完八项检查，逐项给结论 |
| **常用文件夹** | 八个常用目录收在一处，点一下直达 |

#### Mod 依赖关系图

第 0 层在最上面，往下依次是**依赖它的** Mod —— 这个顺序就是加载顺序。

- 缺失的前置画成**红色虚线节点**，一眼看得出断在哪
- 点任意节点，下方显示它依赖谁、又被谁依赖
- 右上角有放大 / 缩小 / 适应窗口；也可以勾上「只看有依赖关系的」，把孤立 Mod 收起来

#### 批量 Mod 信息分析

一次跑完八项检查并逐项给结论：

1. SMAPI 装没装
2. `manifest.json` 能不能解析
3. 有没有重复 `UniqueID`
4. 必需前置齐不齐
5. 前置版本够不够
6. 有没有循环依赖
7. Mods 目录层级对不对
8. 被依赖的 Mod 有没有被禁用

> 和「Mod 冲突检查」看着像，分工其实不同：冲突检查只看**磁盘上有哪些装载毛病**，批量分析是**真的去解析依赖关系**、比对版本、检查 SMAPI。两个都跑一遍也不冲突，结论口径一致。

#### 常用文件夹

Mods 目录、游戏目录、存档目录、SMAPI 日志目录、下载目录、Mod 库、实例目录、数据与日志目录，全收在一处，点「打开」直接在资源管理器里打开。也能**收藏自己的目录**（存在设置文件里，目录改名后列表不残留旧名字）。

### Mod 合集

「Mod 管理 → Mod 合集」是配置档的一个更轻的用法：把**当前启用着的那一套**直接抓成一份快照。

1. 把这一套调好，填个名字（备注可留空），点「保存当前启用为合集」
2. 想切回来时点「套用」——启动器会先列出**将要发生什么**（要启用哪些、要禁用哪些、合集里有几个在磁盘上找不到），确认后才动手
3. 套用只改 Mod 目录名的点前缀，**不删除也不修改任何 Mod 文件**

合集存在 `Data\mod-collections.json`。它和配置档的区别在于：配置档是你手动挑的一套组合，合集是「我此刻正启用着什么」的一键快照 —— 想快速在几套玩法之间来回切，用合集更省事。

### Mod 翻译

「Mod 管理 → Mod 翻译」可以调翻译服务把 Mod 的名称与描述翻成中文。先在「设置 → 网络与账号 → Mod 翻译」里选服务商并填密钥：

| 服务商 | 密钥怎么来 |
| --- | --- |
| 微软翻译（默认） | 在 Azure 建一个 **Translator** 资源，复制密钥；资源有区域的话把区域也填上 |
| 百度翻译 | 把 **APPID 与密钥**按 `APPID:密钥` 的格式填进密钥框 |
| DeepL | 直接填 Auth Key |

翻译结果按 Mod 的标识存在 `Data\mod-translations.json`，请求结果另有缓存（`Data\translate-cache.json`，默认一周过期）。密钥走和其它密钥一样的**加密落盘**，不会写进日志，也不会进反馈包。

### 下载监视器

「运行日志」页右上角有「下载监视器」。启动器里那些耗时操作（一键更新、自动修复、下载、安装等）都登记在同一个任务中心里，这个窗口统一显示：

- **进行中**：标题、状态、进度条；支持取消的能单独取消，也能「全部取消」或「清除已结束」
- **历史**：结束的任务记成一条（成功 / 失败 / 取消、耗时），最多保留 50 条，可一键清空

历史存在 `Data\download-history.json`。
