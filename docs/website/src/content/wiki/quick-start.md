## 第一次打开：跟着向导走

第一次打开启动器时，会先弹一个四步向导：**欢迎 → 选游戏目录 → 检查 SMAPI → 建第一个实例**。

第 2 步会先自动探测游戏目录（Steam / GOG / Xbox / 常见路径），也可以手动选；选中后**立刻校验**，通过了才能进下一步。走完向导就等于把下面这三步做完了，可以跳过直接开玩。

> 只在「没跑过向导 + 一个实例都没有 + 设置里也没记过游戏目录」三个条件都满足时弹一次。

## 第一步：新建实例并选择游戏目录

打开「设置 → 游戏与实例」，确认或手动指定星露谷物语的安装目录。

- **Steam 版**一般能自动找到：启动器会从注册表与 `libraryfolders.vdf` 里定位
- 找不到时手动指到游戏根目录（就是有 `Stardew Valley.exe` 的那一层）

然后到「游戏实例」新建一个实例，选类型：

| 类型 | 启动方式 | 适合 |
| --- | --- | --- |
| **原版** | 直接拉起 `Stardew Valley.exe` | 纯净体验、原版存档 |
| **Mod 端** | 走 SMAPI 启动 | 玩 Mod；Mod 管理功能只对这个实例生效 |

一套原版 + 多套 Mod 端可以同时存在，各自选自己的游戏目录与启动方式；Mod 与存档跟着游戏目录走，不随实例隔离。

## 第二步：装 SMAPI，再装 Mod

到「资源中心」点「下载 SMAPI」：

1. 选择要安装到哪个实例
2. 选线路：**官方**（GitHub Releases）或**云端镜像**（国内可达性更好）
3. 等着装完，实例页会显示当前 SMAPI 版本

> 安装过程中会**弹出一个黑色控制台窗口**，那是 SMAPI 官方安装器自己的窗口，不要关它，几秒后会自动关闭。

装 Mod 有三种方式：

- **导入压缩包**：把 `zip` / `rar` / `7z` / `tar` / `gz` 拖进「Mod 管理」，启动器会识别安装方式
- **在线下载**：到「资源中心 → 在线浏览」，在 Nexus 页面上点「Mod Manager Download」
- **从 Mod 库补齐**：缺前置时直接一键补齐

## 第三步：点启动

回到启动页按下按钮即可。启动前会校验 Mod 与前置依赖，游戏日志实时显示在下方面板里，也可以去「运行日志」页单独看。

## 想和朋友一起种地

到「联机功能」：

1. 填樱花 FRP 的**访问密钥**（免费账号也能开隧道）
2. 「准备 frpc」下载官方客户端
3. 加载节点 → 创建 UDP 隧道（本地端口 **24642**）
4. 点「启动」，页面会出现**域名地址**与 **IP 地址**两栏，各自一键复制，任选一个发给朋友

详见 [联机：樱花 FRP](/wiki/multiplayer/)。
