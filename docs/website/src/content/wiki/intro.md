## 一句话

**星露谷启动器**是一款面向《星露谷物语》的 Windows 桌面工具，把**游戏实例、SMAPI、Mod、存档与联机**收进一个窗口。

它不分发游戏本体，也不修改你的存档，只做「把你手动做会麻烦的事集中到一个界面里」。

## 它解决的问题

| 没有它的时候 | 有了它之后 |
| --- | --- |
| 想同时保留原版存档和 Mod 存档，得手动备份、改名、来回搬 | 一套「原版」+ 多套「Mod 端」实例并存，Mod 目录、存档目录、SMAPI 配置各自独立 |
| 装 SMAPI 要自己找下载页、解压、认安装器、记版本 | 在「资源中心」一键安装，装完自动校验版本 |
| Mod 压缩包格式五花八门，装错位置游戏就报错 | 直接吃 `zip` / `rar` / `7z` / `tar` / `gz`，自动识别安装方式 |
| 覆盖了游戏原始文件，出问题只能重装游戏 | 覆盖前自动备份，装错了可以退回来 |
| Mod 不生效时不知道缺了哪个前置 | 递归解析 `manifest.json`，缺哪个一键补齐 |
| 想联机要自己折腾端口映射 | 填上樱花 FRP 访问密钥，建一条 UDP 隧道并把连接地址复制给朋友 |

## 功能总览

- **实例管理**：一套原版 + 多套 Mod 端，互不干扰
- **Mod 管理**：导入、启用停用、标签分类、Mod 库
- **安装规划**：动手前先列出「会发生什么」（覆盖哪些文件、替换哪些 XNB、装到哪个目录）
- **依赖检查**：递归检查前置关系，可一键补齐
- **一键装 SMAPI**：官方与云端镜像两条线路
- **资源中心**：在线浏览多个 Mod 站点，Nexus 页面上点「Mod Manager Download」即可在启动器内下载（非会员也能用）
- **樱花 FRP 联机**：建 UDP 隧道、一键复制连接地址，页面内嵌官方管理面板
- **运行日志**：启动器操作与游戏输出分两个标签，切走页面也不丢
- **现实天气与月历**：接现实时间与天气，不是游戏内存档
- **个性化背景与主题**：自己的图片 / GIF 当背景，四套配色 + 深浅色

## 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809 及以上 / Windows 11 |
| 架构 | x64 |
| 运行时 | **不需要**单独安装 .NET，exe 已自包含 .NET 8 |
| WebView2 | Windows 11 自带；Windows 10 若在线浏览 Mod 页面时报缺失，装一次免费的 Microsoft Edge WebView2 Runtime |
| 权限 | 普通用户即可，**不需要管理员权限**（联机走普通进程，不装网卡也不装驱动） |
