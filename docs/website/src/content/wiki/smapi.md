## SMAPI 是什么

SMAPI 是星露谷的 Mod 加载器，**所有 Mod 都要靠它才能生效**。它由社区维护（Pathoschild/SMAPI），不是启动器的一部分。

## 在启动器里安装

到「资源中心」点「下载 SMAPI」：

1. 选择安装到哪个 **Mod 端实例**（原版实例不能装）
2. 选下载线路：

| 线路 | 来源 | 说明 |
| --- | --- | --- |
| 官方 | GitHub Releases（Pathoschild/SMAPI） | 总是取最新版 |
| 云端镜像 | 本项目维护的镜像分支 | 国内可达性更好，可选 Gitee 源 |

3. 确认后开始安装，启动器会调用 SMAPI 官方的安装器把文件放进游戏目录

### 那个黑色窗口是什么

安装过程中会弹出一个**控制台窗口**，那是 SMAPI 官方安装器自己的窗口。它必须依赖真实控制台才能运行，启动器无法也不该把它藏起来。

**不要关掉它**，等它自己关闭即可。

### 装完怎么确认

安装结束后启动器会检查游戏目录里的关键文件（`StardewModdingAPI.exe` 等），并把**当前 SMAPI 版本**显示在实例页。

## 更新 SMAPI

- 设置了「检查 SMAPI 更新」时（默认开启），启动器会去查最新版本并在有新版本时提示
- 更新走的是同样的流程：重新下载安装包 → 调用安装器覆盖
- 启动器**不会**自动静默升级，需要你确认

## 关于「启动时自动检查更新」

设置在默认下是**关闭**的，避免频繁请求撞 GitHub API 限流。需要的话可以在设置里打开，或手动点检查。

## 换个实例要重装吗

要。SMAPI 是装在**游戏目录**里的，所有实例共用同一个游戏目录，所以：

- 同一份游戏目录上的多个 Mod 端实例，用的是同一个 SMAPI
- 版本不匹配时，若某个实例的 Mod 需要更高版本 SMAPI，先更新 SMAPI 再启动
