## 原理与前提

《星露谷物语》原版联机走 **UDP**，主机需要把自己的端口暴露到公网。启动器用 **樱花 FRP** 帮你完成这一步。

需要你自己有一个樱花 FRP 账号（免费账号也能开隧道），并拿到**访问密钥**。

> 从 v1.4.0 起联机只走樱花 FRP。此前版本用过另一套组网方案，因为要随包携带第三方闭源网卡驱动，已经移除；现在启动器**不需要管理员权限**，也不装任何驱动。

## 开房五步

### 1. 填访问密钥

到「联机功能」页，把樱花 FRP 面板里的**访问密钥**贴进来，点「验证并加载」。

> 密钥等价于账号密码，只保存在本机 `Data\Settings.json` 里，不会上传、不会进日志。请勿分享给他人。

### 2. 准备 frpc

点「准备 frpc」，启动器会从樱花 FRP 官方接口下载官方客户端，并用接口返回的 **MD5 校验**完整性，存放在 `Data\SakuraFrp\`。只需下载一次。

### 3. 创建隧道

填隧道名（默认「星露谷」）→ 「加载节点」挑一个延迟低的 → 「创建 UDP 隧道」。

- **本地端口必须是 24642**
- 类型必须是 **UDP**（TCP 隧道对星露谷没用）

### 4. 启动隧道

在隧道列表里点「启动」，等页面出现连接地址。没出现说明 frpc 还没连上节点，换个节点或稍等重试。

### 5. 复制地址发给朋友

启动成功后页面会同时给出两种写法：

| 类型 | 形如 | 说明 |
| --- | --- | --- |
| 域名地址 | `frp-xxx.com:10086` | 推荐，IP 变了也能用 |
| IP 地址 | `114.51.4.191:10086` | 域名解析不通时的备用 |

各有一个「复制」按钮，任选其一发给朋友。

## 朋友怎么加入

对方在游戏里走：**合作 → 加入局域网游戏 → 输入你给的地址**。

## 面板就在启动器里

页面右侧内嵌了樱花 FRP 的**官方网页版面板**：建隧道、改名、改端口、删除，登录一次之后都在里面做，不用切到浏览器。

## 注意事项

- **只有 UDP 隧道能用于星露谷**
- **原版联机没有密码**：地址泄露给别人就能进来，不玩时记得点「停止隧道」
- 房主的存档需要有**联机小屋**，否则朋友会卡在角色选择界面
- 房主和朋友的**游戏版本要一致**，Mod 不同步时对方进不来或报错
- 隧道本身由樱花 FRP 服务端维持，使用需遵守其服务条款

## 连不上时的排查顺序

1. 隧道是不是 **UDP** 类型、是不是已经「启动」
2. 页面上有没有出现连接地址（没有就是没连上节点 → 换节点）
3. 地址有没有复制错（冒号、端口）
4. 对方输入的位置对不对（是「加入局域网游戏」，不是「加入 IP 游戏」以外的选项）
5. 还不行看 [故障排查](/wiki/troubleshooting/)
