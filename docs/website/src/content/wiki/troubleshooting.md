## 启动器打不开或一闪就退

按可能性从高到低：

1. **杀毒软件拦截**：启动器是未签名的个人项目 exe，可能被误报。加白名单后再试
2. **解压不完整**：压缩包必须完整解压后再运行，不要在压缩软件里直接双击
3. **放在需要提权的目录**：`Program Files` 下写 `Data\` 会失败，换到用户目录或非系统盘
4. **系统版本过低**：需要 Windows 10 1809 及以上

## 报「没有找到游戏目录」

1. 到「设置 → 游戏与实例」手动指定游戏根目录（含 `Stardew Valley.exe` 的那一层）
2. 确认游戏是 Steam 版且**至少启动过一次**（这样才会有库目录信息）
3. 装在非 Steam 库或移动硬盘上时，只能手动指定

## Mod 装了但游戏里没生效

三个检查点，按顺序排除：

| 检查 | 怎么做 |
| --- | --- |
| 实例类型对不对 | 必须是**Mod 端**实例，原版实例不加载任何 Mod |
| SMAPI 装了吗 | 到「资源中心」装一次；或看实例页显示的 SMAPI 版本 |
| Mod 是否被停用 | 被停用的 Mod 不会加载，在 Mod 管理页重新启用 |
| 缺前置吗 | 在「Mod 管理」跑一次依赖检查，缺哪个补哪个 |
| Mod 版本对吗 | 游戏本体大版本更新后，老 Mod 可能不兼容，看作者说明 |

## 在线浏览页面一片空白

内嵌浏览器依赖 **WebView2**：

- Windows 11 自带
- Windows 10 若提示缺失，装一次免费的 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，装完重启启动器

## 视频背景黑屏或不动

视频背景依赖系统的 **Windows Media Player** 组件：

- 精简版系统（如 Windows 10 LTSC）通常没有这个组件，属于系统限制，无法通过启动器解决
- 解决方式：改用图片或 **GIF 动图**（GIF 是逐帧自己播的，不依赖该组件）
- 注意 H.264 的 `mp4` / `wmv` 兼容性最好

## 下载中断、失败或速度为零

1. 到「运行日志」页看具体报错
2. 下载支持**断点续传**：重新点一次下载会从断点接着走，不必重头来
3. 换下载源（GitHub ↔ Gitee）再试
4. 需要登录或授权才能下载的 Mod，先在「在线浏览」里登录对应站点
5. 临时文件如果坏了，可清掉 `%LOCALAPPDATA%\StardewLauncher\Downloads` 里的残留后重下

## 联机连不上

### 隧道起来了但朋友进不来

1. 隧道必须是 **UDP**（TCP 对星露谷无效），本地端口必须是 **24642**
2. 页面必须**出现了连接地址**；没出现＝frpc 没连上节点 → 换节点重试
3. 地址别复制错（含冒号与端口），域名地址与 IP 地址两个都试一遍
4. 房主存档里要有**联机小屋**
5. 双方**游戏版本一致**；装 Mod 的话，Mod 列表也要基本一致
6. **原版联机没有密码**：确认没有别人占用/干扰，必要时换一条隧道

### 朋友卡在角色选择界面

通常是房里没有**联机小屋**，或朋友的 Mod 与房主差异过大。

### 启动隧道直接失败

- 访问密钥是否有效（在樱花 FRP 面板确认，重新验证一次）
- 密钥只能用于**你自己的账号**，别用别人的
- 隧道数量是否已达你账号的上限

## 设置乱了或界面异常

关闭启动器，把 `Data\Settings.json` 备份后移走，再启动 —— 会回到默认设置。

> 如果这个文件本身损坏（手改过、写入中断），启动器也会自动把坏文件备份、并按默认值重建。

## 怎么反馈问题

带上这三样，问题基本能一次定位：

1. **现象**：点了什么、期望什么、实际什么
2. **日志**：`Data\Log` 目录（或「运行日志」页里直接看），把最相关的那份附上
3. **环境**：Windows 版本（`winver`）、游戏版本、启动器版本、是否装了 SMAPI 及其版本
