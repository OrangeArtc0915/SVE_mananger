## 界面

### 明暗模式

浅色 / 深色 / **跟随系统**。选跟随系统时会跟着 Windows 的应用模式自动切换。

### 强调色

四套预设：**星露谷**（默认，暖焦糖）、**湖蓝**、**莓果**、**秋日**。上方色板是实时预览，点一下就换。

也可以自己调：

- **色相滑块**（0-359）：拖动即改即看，整站强调色（按钮、胶囊、图标、渐变）跟着变；拖动过程中只改内存，**松手或按方向键**后才写进设置文件
- **按色值**：在旁边的输入框里填 `#E67E22` 这样的六位十六进制色值，点「按色值」应用
- **用预设配色**：放弃自定义色，回到四套预设
- 点四套预设里任意一个也会**自动放弃自定义色**

### 面板不透明度

四档：**更透**（60）/ **默认**（78）/ **更实**（90）/ **不透明**（100）。影响侧栏、标题栏与卡片这类半透明面板，数值越大越实、背景图越看不出来。

### 窗口背景

- **选择图片或视频**：支持 `jpg` / `png` / `bmp` / `gif` / `mp4` / `wmv` / `avi`
  - GIF 会**逐帧播放**（不是只播第一帧）
  - 视频会**循环静音**播放，且依赖系统的 Windows Media Player 组件，精简系统（如 Windows 10 LTSC）可能不支持，此时请用图片或 GIF
- **铺放方式**：铺满（默认，不留空边）/ 完整（可能留空边）/ 拉伸（可能变形）
- **压暗程度**：0-80，默认约 45。背景铺满整个窗口、面板半透明、页面标题直接压在背景上，所以建议留着压暗，否则标题看不清
- 选中的文件会被**复制进数据目录**，之后你移动或删除原文件都不影响

### 首页小组件

主页一共有 **6 张卡片**：月历、现实天气、每日一言、存档概览、自定义图片、Mod 概览。

- **存档概览**：读游戏存档目录里最近保存的那份，显示「玩家名 · 农场名」「第 X 年季节 第几天 · 金钱 · 游玩时长」和五项技能（有多个存档时补一句共几个）；读不到时显示「还没扫到存档」
- **自定义图片**：自己选一张 `jpg` / `png` / `bmp` / `gif`，启动器会把图**复制一份**到 `Data\Homepage\` 再显示，之后原图移动 / 删除都不影响；卡片上有「换图」「移除」，文件丢了会给一条提示
- **Mod 概览**：显示当前实例名、「共 N 个 · 启用 X · 禁用 Y（有异常时补 · 异常 Z）」以及 SMAPI 版本（有新版时写成 `SMAPI 4.5.1（有新版 4.5.2）`）；原版实例会写「这是原版实例，不加载 Mod」，没装 SMAPI 会写「当前实例没装 SMAPI」

卡片可以**用鼠标拖动调整先后顺序**（在卡片上按住拖，从按钮上起拖不会被抢），工具条的「自定义」菜单里可以勾选显示 / 隐藏、「恢复默认顺序」，以及：

- **导出布局…**：导出一个 json（顺序 + 显隐 + 图片挂件的图路径），换机 / 重装后导回来即可
- **导入布局…**：导入时如果图在那台机器上不存在，会提示「需要重新选一张」

顺序与显隐会**自动记进设置**（`HomepageWidgetOrder` / `HomepageHiddenWidgets`），不需要你手动设。

## 侧栏导航

侧栏 8 个导航项（启动 / Mod 管理 / 游戏实例 / 资源中心 / 联机功能 / 工具箱 / 设置 / 运行日志）可以自己调顺序和收放：

- 用「上移」「下移」调整先后顺序
- 用「收起」/「显示」把不常用的项藏起来
- 右边按钮点一下就生效，底部还有「恢复默认顺序」

顺序与显隐存在设置里（`NavOrder` / `NavHidden`），重启后保持。

## 游戏与实例

- **当前实例**：显示当前选中的实例，可在此切换
- **游戏目录**：显示自动定位到的路径，可手动指定（含 `Stardew Valley.exe` 的那一层），也能一键打开
- **SMAPI**：显示当前 SMAPI 版本，并提供「打开 SMAPI 下载页」
- **更新检查**：三个独立开关
  - 启动时自动检查更新：默认关闭（避免频繁请求撞限流）
  - 检查 Mod 更新：默认开启，每次进 Mod 管理页顺带查一次，结果缓存 6 小时（详见 [Mod 管理](/wiki/mods/)）
  - 检查 SMAPI 更新：默认开启
- **存档**：显示存档目录，可一键打开

## 存档备份

「工具箱 → 存档管理」里的备份行为由两个设置控制，它们写在 `Data\Settings.json` 里（设置界面暂无对应控件）：

| 设置项 | 默认 | 作用 |
| --- | --- | --- |
| `SaveBackupKeepCount` | 10 | 每个存档最多保留几份备份，超出后自动删掉最旧的 |
| `SnapshotBeforeRestore` | 开 | 回滚前是否自动给当前存档打一份 `-auto` 快照；关掉后回滚不可撤销 |

「删除到回收站」这个开关同样作用于备份的删除。用法详见 [存档管理](/wiki/saves/)。

## Mod 与存储

### Mod 库目录

存放「已解压、待安装」的 Mod。Mod 管理页可以从中勾选并批量安装到游戏目录。

可以手动选择、自动检测、或直接打开。Mod 数量多时建议放到空间大的盘。

### 入库方式

开启后，从启动器下载的 Mod 会**自动入库并装进当前实例的 Mods 目录**；同名 Mod 会先备份。

### 下载源

**GitHub**（默认）或 **Gitee**。国内访问 GitHub 慢时切到 Gitee。

### nxm:// 协议关联

开启后，在浏览器里点 Mod 站点的「Mod Manager Download」会直接唤起启动器下载，不用先下载到本地再导入。

## 密钥与账号

### Nexus API Key

- 用于**查询 Mod 详情**与**在线下载**，可选
- **检查模组更新不需要它**（走公开接口）
- 填好后可以「保存」「验证账号」，并查看当前配额
- 只保存在本机 `Data\Settings.json`，界面上只显示掩码

### 在线下载 Mod

从设置页也能直接跳到在线浏览页面。

## 天气与位置

填**城市名**（支持中文，例如「杭州」「北京」）后点「保存并测试」，主页的天气小组件就会显示该城市的天气。

数据来自 **Open-Meteo**：免费公开接口、**无需密钥**。也可以点「刷新天气」强制更新。

## 目录与日志

| 项 | 说明 |
| --- | --- |
| **数据目录** | 启动器的所有数据（实例、设置、背景、缓存、日志）都在这里，可一键打开 |
| **下载目录** | 监控浏览器下载的 Mod，便于一键入库；可修改，也可以恢复默认 |
| **日志目录** | 落盘日志位置。日志按大小滚动，自动保留最近若干份 |

## 数据存在哪

所有设置都写在 `Data\Settings.json`（数据目录可用环境变量 `STARDEWLAUNCHER_DATA` 重定向）。想换机器时，把整个 `Data\` 一起带走即可保留你的实例与设置。

本轮新增的自定义项也在这个文件里：

| 设置项 | 默认 | 作用 |
| --- | --- | --- |
| `AccentHue` | -1 | 自定义强调色的色相（0-359）；`-1` 表示用四套预设 |
| `AccentSaturation` | 68 | 自定义强调色的饱和度（8-100） |
| `PanelOpacity` | 78 | 半透明面板的不透明度（55-100），越大越实 |
| `NavOrder` | 空 | 侧栏导航顺序；留空表示用默认顺序 |
| `NavHidden` | 空 | 被收起的侧栏导航项 |
| `HomepageImageFile` | 空 | 「自定义图片」小组件用的图（存在数据目录里） |

> `Settings.json` 里含有 Nexus 与樱花 FRP 的密钥，**不要把这个文件发给别人或传到网上**。
