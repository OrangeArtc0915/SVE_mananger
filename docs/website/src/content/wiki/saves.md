## 存档在哪

星露谷的存档由游戏自己管理，固定在：

```
%APPDATA%\StardewValley\Saves\<存档Id>\
```

注意是 Roaming 下的 `%APPDATA%`。侧栏「存档」页读的就是这个目录：启动器只读取，**不复制、不搬移、不删改**你的存档。页面顶部的「打开存档目录」可以直接跳过去。

> 一个存档目录 = 一个文件夹，文件夹名就是游戏内部的存档 Id；目录里必须有游戏写的 `SaveGameInfo`，否则启动器不把它当成有效存档。

## 卡片上写了什么

每张卡片是一份存档。摘要全部读自存档目录里的 `SaveGameInfo`（游戏自己写的小文件），不会把几百 MB 的主存档整块读进内存：

| 显示 | 含义 |
| --- | --- |
| 玩家名 / 农场名 | 角色名与农场名，农场没命名时显示「（未命名农场）」 |
| 第 X 年 季节 第几日 · Ng · 游玩时长 | 游戏内进度、当前金钱、累计游玩时间 |
| 五项技能 | 耕种 / 采矿 / 觅食 / 钓鱼 / 战斗的等级 |
| 最后保存 · 体积 | 主存档文件的最后写入时间，以及整个存档目录的大小 |
| N 份备份 | 这个存档在启动器里已经有多少份备份 |

列表按最后保存时间倒序。存档目录不存在、或里面没有可识别的存档时，会显示一段说明文字告诉你原因。

> 卡片上出现红字「主存档缺失，别用这份恢复」，说明那个存档目录里缺了主存档文件（只有 `SaveGameInfo`），这份存档已经不完整了。

## 备份

一份备份 = 把整个存档目录**整目录复制**一份。三个入口：

- 卡片上的「备份」：只备份这一份
- 工具栏的「全部备份一次」：给列表里每个存档各备份一份
- 「备份与回滚…」窗口里的「新建备份」

## 备份与回滚…

点卡片上的「备份与回滚…」打开这个存档的备份管理窗口，里面按时间倒序列出全部备份，每一行都能：

| 操作 | 说明 |
| --- | --- |
| 恢复 | 用这份备份覆盖回存档目录 |
| 删除 | 删掉这份备份，跟随设置里的「删除到回收站」（默认开启，误删可救） |

回滚要注意两件事：

- **恢复前会自动给当前存档打一份快照**（目录名带 `-auto` 后缀），所以回滚本身也能反悔。这份快照失败时会中止回滚，避免出现「恢复完却退不回去」。不想留这个保护，见下面的设置项。
- **游戏运行中不能回滚**，会先要求你退出游戏。游戏中保存会把回滚结果覆盖掉，而且存档文件可能正被占用。

游戏中**可以备份**，但备份的是上次保存的状态 —— 游戏里还没保存的进度不在里面。

回滚完成后，已经打开的游戏不会感知这次改动，进游戏即可看到结果。

## 备份存在哪

备份**不放进游戏存档目录**，而是放在启动器自己的数据目录：

```
Data\save-backups\<存档Id>\<yyyyMMdd-HHmmss>\
```

一份备份一个时间戳文件夹，自动快照多一个 `-auto` 后缀。这么放是为了避免备份文件被 Steam 云同步一起带走。

窗口右上角的「打开备份目录」可以直接跳到这个存档的备份文件夹。

## 保留份数与设置项

备份策略由两个设置控制，它们写在 `Data\Settings.json` 里（设置界面暂无对应控件）：

| 设置项 | 默认 | 作用 |
| --- | --- | --- |
| `SaveBackupKeepCount` | 10 | 每个存档最多保留几份备份，超出后自动删掉最旧的 |
| `SnapshotBeforeRestore` | 开 | 回滚前是否自动给当前存档打一份快照 |

设置里「删除到回收站」也会影响备份的删除方式：开启时删备份是送进回收站，关掉则是永久删除。

## 启动器不会删改你的存档

再强调一次：存档页只做两件事 —— 读摘要、往启动器的数据目录里写备份。删除操作只会删 `Data\save-backups\` 下启动器自己建的备份，**不会去动 `%APPDATA%\StardewValley\Saves` 里的任何文件**。

> 如果同时开着 Steam 云同步，建议不要让两个工具同时改写同一份存档。
