Features

它能帮你做什么

九件事，把小农场打理得井井有条：从装 SMAPI、建实例、装 Mod，到查依赖、下资源、看天气，再到开条隧道和朋友一起种地。

一键装 SMAPI

在「资源中心」点一下就能装 SMAPI，装完自动校验版本，不用再手动解压、找安装脚本。

两条线路任选：官方 GitHub Releases，或启动器自建云端镜像（国内可选 Gitee 源）。

实例管理

原版与 Mod 端分开建实例，各自的 Mods、SMAPI 与存档互不干扰。

想体验纯净存档时，切回原版实例就能直接开。

Mod 管理（zip / rar / 7z）

扫描、启用、停用、删除、导入，一次看清每个 Mod 的状态。

压缩包支持 zip / rar / 7z，拖进来就能用。

安装规划

Content 覆盖、XNB 替换、Reshade 这类非标准包，也能按规划装进游戏目录。

覆盖之前先自动备份，装错了随时能退回来。

依赖检查与一键补齐

谁缺前置、缺哪一个，列表里一目了然。

缺的 Mod 可以从本地 Mod 库一键补齐。

资源中心

下载 Mod、安装 SMAPI、内嵌浏览器直连八个 Mod 站点，都在这一页里，不用切出去。

Nexus 页面上点「Mod Manager Download」即可在启动器内下载，非会员也能用。

现实天气与月历

主页按真实日期排当月月历，并显示你所在城市的天气。

数据来自 Open-Meteo，不需要填任何 Key。

樱花 FRP 联机

填上自己的樱花 FRP 访问密钥、选个节点，启动器就帮你建一条 UDP 24642 隧道并拉起官方 frpc，连接地址一键复制。

frpc 不在安装包里，由启动器从樱花 FRP 官方接口下载并校验；隧道建好把地址发给朋友，他们按游戏自带的局域网联机进来。

个性化背景与主题

背景可以换成自己的图片或 GIF 动图，界面是半透明的玻璃质感，背景会从面板后面透出来。

四套配色（暖焦糖 / 天青 / 莓粉 / 秋绿）配深浅色切换，界面跟着一起变。

Get Started

三步开种

第一次用也不用怕，跟着走一遍就好。

1

新建实例并选择游戏目录

在「游戏实例」里新建一个实例，指向你的星露谷物语安装目录；想要纯净体验就选原版，想玩 Mod 就选 Mod 端。

2

先装 SMAPI，再装 Mod

在「资源中心」点「下载 SMAPI」，官方或云端镜像两条线路任选，装完启动器会校验版本。然后把压缩包导入 Mod 库，或在线下载安装；缺前置会顺手提醒。

3

点启动，或者拉朋友一起种

回到启动页按下按钮就行。启动前会校验 Mod 与前置依赖，游戏日志也会实时显示在下面的面板里。

想和朋友一起种地，就到「樱花联机」开一条 UDP 隧道，把复制到的连接地址发过去，对方在游戏里加入即可。

FAQ

常见问题

点开就能看到答案。

启动器会不会影响成就？

启动器本身只负责启动游戏、管理文件和显示日志，不会修改存档或成就数据。不过要注意：装了 Mod 之后，游戏内的成就就是「有 Mod 的存档」的正常逻辑，这一点和启动器无关。

怎么让 Mod 生效？

需要先装好 SMAPI，并用 Mod 端实例启动游戏。装 SMAPI 不用出启动器：到「资源中心」点「下载 SMAPI」，选好游戏实例后一键安装即可。装好之后，实例页会显示当前 SMAPI 版本。

装 SMAPI 时冒出一个黑窗口，是不是出问题了？

不是。那是 SMAPI 官方安装器自己的控制台窗口，它必须依赖真实控制台才能运行，启动器无法也不该把它藏起来。等它自己关掉就好，之后启动器会校验安装结果并把版本显示出来。

为什么下载很慢？

下载速度取决于本机网络与站点线路，启动器只做转发、不缓存也不加速。如果实在太慢，可以先用浏览器下载好，再用「导入」把压缩包放进 Mod 库安装，效果是一样的。

樱花 FRP 要花钱吗？

需要你自己在樱花 FRP 面板拿一个访问密钥，免费账号也能开隧道。星露谷联机走 UDP，隧道要建 UDP 类型（本地端口 24642），TCP 隧道用不了。

开了隧道，朋友却连不上？

先确认隧道是 UDP 类型、已经启动，并且页面上出现了连接地址（没出现说明 frpc 还没连上节点）。把「复制地址」得到的地址原样发给对方，对方在游戏里走「合作 → 加入局域网游戏 → 输入地址」。

能把视频设成背景吗？

可以，但视频背景依赖系统自带的 Windows Media Player 组件。部分精简系统（如 Windows 10 LTSC）没有这个组件，此时请改用图片或 GIF 动图。

存档在哪？会不会丢？

存档默认在 %appdata%\StardewValley\Saves。启动器只读取路径信息，不会主动删改存档；如果同时开着 Steam 云同步，建议不要让两个工具同时改写同一份存档，以免互相覆盖。
